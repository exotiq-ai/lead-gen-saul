What the Agent Does Every 15 Minutes

Each run takes about 30-90 seconds, then Railway goes back to sleep.

1
Discover
Searches the web for new exotic car rental operators. Adds them to the database.
2
Enrich
Looks up company details via Apollo (Exotiq) or Google Places (MedSpa). Fleet size, website, etc.
3
Score
Calculates an ICP fit score (0-100) based on fleet size, market, online presence, engagement.
4
GHL Poll
Checks GoHighLevel for new messages. If a lead replied, logs it and marks them "engaged."
5
Draft
For high-scoring leads, writes a personalized outreach message. Puts it in the approval queue.
6
AI Insights
Analyzes replies, diagnoses cold leads, assesses new discoveries, reviews draft quality, writes the daily summary.

Nothing sends automatically. The agent drafts messages and puts them in a queue. Gregory clicks "Approve" in the dashboard before anything goes out.

Claude Code vs Railway — Going Forward

You do NOT need Claude Code to keep the system running.

Railway handles the scheduling and execution. The Python agent runs itself. AI insights use the OpenAI API directly (no Claude Code SDK needed).

When you'd use Claude Code (or me) again:

Only when you want to change or add features:

  • New outreach templates or scoring logic
  • Add a new tenant (e.g., a third vertical)
  • Build new dashboard pages or features
  • Fix bugs or adjust thresholds
  • Mobile optimization phase
  • Add action buttons to Daily Brief insight cards

Think of it like this: Railway is the engine that runs 24/7. Claude Code is the mechanic you call when you want upgrades.
